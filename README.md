## 📌 Sobre o Projeto

O objetivo deste repositório é acompanhar a evolução prática do servidor web construído ao longo do semestre utilizando **Python e Flask**, cobrindo o ciclo completo de desenvolvimento de aplicações web backend:

* **Estrutura Básica & Templates:** Rotas HTTP, renderização dinâmica de páginas via Jinja2 e integração de arquivos estáticos (CSS/JS).
* **Formulários Web:** Captura, tratamento e validação de dados submetidos via formulários.
* **Persistência em Banco de Dados:** Modelagem e manipulação de dados na aplicação Flask.
* **Integração de Serviços de E-mail:** Envio automático de mensagens e notificações via aplicação.
* **Autenticação & Controle de Acesso:** Login, controle de sessões e segurança do usuário.
* **Arquitetura Completa:** Consolidação dos módulos em uma aplicação web estruturada e modular.

## 🚀 Como Executar o Projeto Localmente

### Pré-requisitos

Possuir o **Python 3.10** instalado.

### Passo a Passo

1. **Clone o repositório:**
```bash
git clone [https://github.com/brondileticia/devweb-servidor-flask.git](https://github.com/brondileticia/devweb-servidor-flask.git)
cd devweb-servidor-flask

```


2. **Crie e ative um ambiente virtual (`venv`):**
* **Windows:**
```bash
python -m venv venv
.\venv\Scripts\activate

```


* **Linux/Mac:**
```bash
python3 -m venv venv
source venv/bin/activate

```




3. **Instale as dependências:**
```bash
pip install -r requirements.txt

```


4. **Execute o servidor:**
```bash
python app.py

```


5. **Acesse no navegador:**
Navegue para `http://127.0.0.1:5000/`.
